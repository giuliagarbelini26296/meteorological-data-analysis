# Análise Meteorológica - São Paulo Interlagos (2025)

Projeto de análise exploratória de dados meteorológicos utilizando dados reais do INMET e linguagem R.

## Objetivo

O objetivo deste projeto é analisar padrões meteorológicos na estação de São Paulo - Interlagos ao longo de 2025, utilizando técnicas de limpeza, tratamento e visualização de dados.

## Dados utilizados

Os dados foram obtidos através do Instituto Nacional de Meteorologia (INMET).

Fonte:
  https://portal.inmet.gov.br/dadoshistoricos

## Ferramentas utilizadas

- R
- RStudio
- tidyverse
- ggplot2
- lubridate

## Análises realizadas

- Temperatura média diária
- Distribuição mensal da temperatura
- Precipitação diária
- Tratamento e limpeza de dados meteorológicos
